# NEON CORE — versión mejorada v2

Juego web de reflejos y estrategia para navegador.

## Mejoras incluidas
- Animación del reactor corregida: el canvas ahora se actualiza continuamente.
- Respuesta más rápida en PC y celular usando `pointerdown`.
- Modo automático optimizado y con velocidad según dificultad.
- Dificultades NORMAL, DIFÍCIL y PRO.
- Niveles progresivos hasta 7 nodos.
- Energía, combo, puntuación y récord guardado en `localStorage`.
- Récord persistente aunque cierres el navegador.
- Pausa automática al cambiar de ventana/pestaña.
- Botón SALIR y reinicio limpio.
- Efectos de partículas, escaneo y subida de nivel.
- Diseño responsive para celular y PC.
- Sin librerías ni instalación.

## Cómo abrir
1. Descomprimí el ZIP.
2. Abrí la carpeta en Visual Studio Code.
3. Abrí `index.html`.
4. Recomendado: ejecutarlo con Live Server.

## Archivos
- `index.html` — estructura y pantallas.
- `style.css` — diseño y adaptación móvil.
- `script.js` — lógica completa del juego.
